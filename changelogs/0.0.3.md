## Changelog for release 0.0.3

Release 0.0.3 addresses the following changes:

- Made the token for two-factor-tokens format agnostic
- Added default formats:
    - Email token: 6-digit otp
    - Refresh token: UUID

- Changed email logic: now using kotlinx.html system
- Added email triggers
  - Invitation created
  - Invitation denied
  - Invitation accepted
  - Invitation revoked
- Made name of email be branded
- Added button-links to email
